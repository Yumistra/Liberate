# Liberate — Revenge Next

DISTORTED HEAVENS as a Revenge Next theme plugin (Themes API): colors, background and fonts.

Add this repository in Revenge → Plugins:

```
https://raw.githubusercontent.com/Yumistra/Liberate/revenge-dist
```

Edit `Discord/my-theme.json` (colors, background) or `Discord/my-ttf.json` (fonts) and push. The workflow regenerates the plugin and publishes it to the `revenge-dist` branch. Bump `version` in `revenge/plugins/distorted-heavens/manifest.json` so Revenge offers the update.
